這一版的設計方向

  • 主角是九支球桶。首頁把九款排成一排球架，點哪一支就進哪一款。每一款的產品頁底色跟著球桶顏色走，球友記得的是顏色。
  • 色調沿用 KOMBO 包裝。暖紙底、品牌藍、朱紅，全部取樣自包裝實物。深藍只用在頁尾。
  • 大品牌官網的做法，KOMBO 自己的樣子。型錄導購、不設購物車；不做輪播大圖、不放選手代言、不用深色主視覺，避免和李寧、勝利產生聯想。
  • 手機優先。手機上球架可以左右滑，畫面底部常駐「到蝦皮購買」與「LINE 詢問」。
  • 下單交給通路。蝦皮可以直達該款商品；賣貨便、好賣+ 只能連到賣場，按鈕寫「選購」，避免點過去找不到。

需要您確認

  1. Q-1「商店資訊」只有線上通路，還是也有實體店、經銷商或球館要列？
  2. Q-2型錄與產品頁要不要顯示價格？目前價格是 9/18 從賣貨便查到的。
  3. Q-3產品清單是否正確？No.5+ 的售價、每桶顆數、球頭材質、每款一句話說明需要補上。
  4. Q-4每一款在蝦皮的商品網址，以及全家好賣+ 的賣場網址。
  5. Q-8能否提供各款球的高解析度照片？現有單品圖寬度只有 110 像素，電腦版產品頁會不夠清楚。
  6. 文案材質說明與首頁介紹文字是草稿，品牌官方文案則逐字未改。

設計稿中的通路與 LINE 連結是實際連結；標示「待確認」的連結尚未取得正確網址。
