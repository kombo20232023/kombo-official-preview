# KOMBO 官網：決策方向與時間成本

2026-10-08

## 結論

**第一版就是純 DM 官網，上線時程由您決定。**我們提供每個決定的方向與成本；**影響上線日期最大的，是每一輪意見的來回次數與回覆時間，不是製作時間。**

## 1. 第一版做什麼、不做什麼

| 範圍 | 狀態 |
|---|---|
| 官網前台（設計稿 v3：首頁、羽毛球、球拍、配件、商品頁、銷售通路、最新消息、品牌故事、聯絡我們） | **第一版要做** |
| 後台設計稿 admin-v1、資料庫與上架架構 | 參考，**不在第一版**；要做時另行評估 |
| 營運成本估計 | 參考；第一版純 DM 只需要網域，主機用免費託管（見「營運成本」分頁） |

## 2. 時間怎麼花掉的（實際紀錄）

| 時間 | 事件 | 間隔 |
|---|---|---|
| 10/2 10:50 | 設計稿 v2 完成 | |
| 10/7 12:30 | 收到意見：「希望像李寧，簡單明瞭」 | **間隔 5 天**（含設計稿送達與看稿） |
| 10/7 13:06 | 設計稿 v3 完成 | 製作約 36 分鐘 |

**每一輪 ＝ 您看稿與回覆 ＋ 我們修改。**上一輪的修改在收到意見當天就完成，所以上線日期主要取決於：

1. **來回幾輪**：每多一輪，就多一次「等回覆」。
2. **每輪隔多久回覆**：以上一輪為例，從完成到收到意見的間隔，是製作時間的 200 倍以上。
3. **意見是否一次給齊**：零星意見會拆成更多輪。

### 建議做法

- 用預覽網站的「v3 逐項反饋」**一次看完 29 項**，填完按「寄出備份」，我們就能一次改完。
- **先約定輪數上限**：例如最多兩輪就定版，定版後的新想法列入第二版，不影響第一版上線。
- 待提供的資料（商品照片、價格、通路網址）越早給，越不會卡在最後一步。

## 3. 上線前需要您決定或提供的事

| 項目 | 不決定的影響 |
|---|---|
| 結構與風格可以像李寧嗎（Q-D） | 會影響整體方向，最優先 |
| 主視覺圖片（電腦橫式、手機直式各一組） | 上線時先用球桶照代替 |
| 頁面最上方公告條要不要放、放什麼 | 不放就拿掉，不影響上線 |
| 有無實體據點（Q-1）、要不要顯示價格（Q-2） | 銷售通路頁與商品頁的內容 |
| 商品資料：No.5+ 售價、每桶顆數、球頭、每款一句話（Q-3）；球拍型號與照片 | 缺的欄位上線時顯示「—」或不顯示 |
| 蝦皮各商品網址、全家好賣+ 賣場網址（Q-4） | 缺的通路按鈕先不放 |
| 高解析度商品照片（Q-8） | 電腦版商品圖會偏小 |
| 網域（例如 .tw） | 先用免費網址上線，之後可換 |

## 4. 請先說清楚：要「交付」還是「實驗」

| | 交付 | 實驗 |
|---|---|---|
| 目的 | 在約定日期上線一個可用的官網 | 探索方向、看看有哪些可能 |
| 時程 | 約定上線日與輪數上限 | 不承諾上線日 |
| 定版後的新想法 | 列入第二版 | 隨時可以試 |
| 投入時間 | 有上限，可預估 | 依實際來回次數 |

兩種都可以，**事先說清楚，彼此對時間與成本的預期才會一致**。若沒有特別說明，我們以「交付」為準。
