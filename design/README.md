## 怎麼看

每一版是可以直接用瀏覽器開啟的網頁，入口是該版本資料夾的 `index.html`。設計稿用的圖片、字體與資料都在版本資料夾內，不依賴 `src/`，所以舊版本不會因為正式網站改動而走樣。

## live demo

每一版審閱中的設計稿同時發布成可操作的網頁（Claude Artifact），給客戶在手機上直接點。發布內容與該版資料夾相同，只有封面頁 `index.html` 會去掉外層的 `<html>`／`<head>`／`<body>` 標籤（發布平台會自己包一層）。

Artifact 環境的限制，設計稿已配合：
- 網址只保留 `#` 之後的部分，所以頁面狀態用 `#` 傳遞（例如 `product.html#no-3a`），不用 `?sku=`
- 系統分享選單會被擋，分享按鈕會改為複製連結；複製到的是 artifact 內部網址，正式網站上線後才會是商品頁網址

## 規則

- 給客戶看過的版本就凍結，修改一律開新版本資料夾。
- 每一版在 [`CHANGELOG.md`](CHANGELOG.md) 記一筆。
- 設計稿裡標示「待確認」的地方，對應 [008 的待確認問題](../specs/001-需求文件/008-v1-dm-scope.md#待確認問題)。
