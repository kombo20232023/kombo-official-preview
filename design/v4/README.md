# 設計稿 v4

入口：[index.html](index.html)（審閱封面頁，可切換手機、平板、電腦尺寸預覽）。

以 [v3](../v3/README.md) 為底（v3 已給客戶看過，凍結不改），依[客戶回饋 2](../../specs/001-需求文件/訪談/2026-10-19-客戶回饋2.md)（2026-10-19，心萍的 v3 逐項反饋，[原文](../../specs/001-需求文件/訪談/2026-10-19-v3-feedback-心萍.txt)）修改。

## 這一版改了什麼

逐條對應客戶回饋 2 的「已確定」表格。

| 客戶回饋 2 的項目 | v4 的做法 |
|---|---|
| 公告條：保留，有暫停出貨時顯示 | 保留公告條，文字示意「暫停出貨時在這裡公告」，標待確認 |
| LOGO 客戶提供 | 標誌維持現有，品牌帶加待確認標記「LOGO 客戶提供」 |
| 商品分類（5 類） | 鵝毛羽毛球、鴨毛羽毛球、羽球拍、服飾配件、羽毛球相關配件；頁首「商品系列」下拉、手機選單、底部固定列的「商品分類」都用這 5 類（資料在 `assets/data.js` 的 `categories`） |
| 首頁輪播：三張，活動、新商品、品牌故事；圖片客戶提供 | 滿版輪播三張：①活動免運（雙 11、雙 12 等短期活動時換圖）②新商品（以 No.5+（K5+）示意）③品牌故事；每張都標「圖片客戶提供」 |
| 首頁輪播下方：用 v2 的系列呈現，文字改成商品分類；下面接 v3 的最新消息 | 移植 v2 首頁「系列」區塊的主題橫幅版型（`design/v2/assets/site.js` 的 `renderBanners`，CSS `.banner` 沿用 v2 規則），內容換成 5 個商品分類，只放分類名稱；下方接 v3 的最新消息 |
| 首頁商品格只放分類 | 拿掉 v3 的系列海報、標語、全系列商品格、依材質選球、通路橫幅 |
| 羽毛球列表分類：全部／鵝毛球／鴨毛球，不放文字介紹 | 側欄（手機為橫滑列）只有這三個；拿掉 v3 的材質說明段 |
| 鵝毛球：K1、K3A、K5A、K8、訓練用球；鴨毛球：K3、K5+、K5、K6、KD | 依這個順序；每個商品加 `group`（goose／duck）。訓練用球併入鵝毛球、可點進商品頁 |
| K7 Pro 應該會下架 | 資料本來就沒有 K7 Pro，不加 |
| 商品名稱寫成「No.1（K1）」並註明 K 是 KOMBO 的簡稱 | 卡片、商品頁、選單、相關商品都用「No.1（K1）」；羽毛球列表頁頂端註明一次「商品名稱中的 K 是 KOMBO 的簡稱」 |
| 列表價格下方顯示毛片等級，不顯示球速 | 每個商品加 `grade`（毛片等級對照表）；K6「三級水鴨」標待確認 |
| 配件拆成兩頁 | `apparel.html`（機能襪、提袋）、`gear.html`（增耐藥水、握把布、羽球拍絨布袋），歸類標「分類待客戶確認」；所有連結改指新頁 |
| 球拍列表：可以，暫定 | 版型不變；頁面標題由「球拍」改為「羽球拍」，與分類名稱一致 |
| 商品頁圖片用 v2 的呈現 | 主圖下方一直顯示縮圖列（v3 手機版把縮圖收起、只顯示張數，v4 改回 v2 的縮圖列，手機也顯示），縮圖可點換主圖 |
| 商品頁結構 | 名稱 → 商品編號 → 商品介紹 → 星等（飛行、耐用度、穩定性）→ 羽毛／球頭／規格 → 球速選擇 → 售價 → 四個通路按鈕 → 「售價與庫存以各通路頁面為準。」→ 分享這款 → 注意事項 → 你可能也喜歡。拿掉商品介紹與規格說明分頁 |
| K1 的介紹、星等、規格 | 照客戶原文；其他商品的介紹、星等、球頭、規格標「客戶提供」；羽毛欄位用毛片等級對照表 |
| 商品頁注意事項 | 兩條照客戶原文，「顧無法挑選」改為「故無法挑選」 |
| 通路：7-11 賣貨便、全家好賣+、樂天市場、LINE 宅配 | 拿掉蝦皮；按鈕第一行是「在 7-11 賣貨便選購」等，付款方式放在按鈕右側小字；樂天市場、好賣+ 網址標待確認 |
| 銷售通路頁：不分類、四個通路直接列出、不放 QR Code、文案客戶再想 | 拿掉類型篩選與 LINE QR Code；四個通路的說明照客戶原文；整頁標「文案客戶再想」 |
| 聯絡我們：三類；下方不放 LINE，改成留言板 | 選球諮詢（沿用 v3 文字）、大量購買、其他問題；下方改成留言板示意（姓名、電子信箱、留言、送出；送出不會真的寄出），說明文字照客戶原文；整區標「留言板是否放第一版待業主決定（R-7）」 |
| 找不到頁面文案 | 「網址可能打錯了，或這一款已經改名。從選單重新找找看。」 |
| 頁尾：購買與聯絡加電子信箱；社群加 Threads | 電子信箱照客戶所寫「Kombooo2023@gmial.com」並標「R-6 請確認拼字」；Threads 網址標待確認 |
| 型錄下載：PDF 和照片檔（R-2） | 兩個下載按鈕（示意），標待確認 |
| 品牌故事：未看 | 不改 |

所有 `?v=` 快取參數改為 `?v=20261020`。

## 資料與素材

- 內容集中在 [assets/data.js](assets/data.js)：`categories`（5 類）、`materials`（鵝毛球、鴨毛球兩組）、`products`（加 `group`、`grade`，K1 另有 `intro`、`stars`、`head`、`spec`）、`channels`（四個通路）、`notices`（注意事項）、`accessories`（加 `cat`）。
- 球桶 PNG 與 v3 相同；訓練用球沒有照片，顯示「照片待提供」。
- v4 的樣式覆寫集中在 [assets/site.css](assets/site.css) 檔尾「v4」區塊。
- 字體由 Google Fonts 載入；v4 不再使用 qrcodejs。

## 怎麼看

**不要直接雙擊開 HTML 檔**，請在這個資料夾啟動靜態伺服器：

```bash
python3 -m http.server 8080
```

再開 <http://localhost:8080/>。封面頁勾選「隱藏待確認標記」後，所有頁面都會隱藏（存在瀏覽器裡）；本機也可以在網址加上 `?clean=1`。

也可以用 Streamlit 預覽 app 看：在 repo 根目錄執行 `streamlit run streamlit_app.py`，見[設計稿預覽 app](../../docs/設計稿預覽app.md)。
